Setup guide — connect Google Sheets (5 minutes)
  1. Go to sheets.google.com and create a new Google Sheet. Name it Grace Chemicals Social Planner.
  2. Click Extensions → Apps Script. Delete any default code.
  3. Paste the entire contents of grace-planner-apps-script.gs (the other file provided) into the editor. Click Save (Ctrl+S).
  4. Click Deploy → New deployment. Choose type: Web app.
  5. Set Execute as: Me. Set Who has access: Anyone. Click Deploy.
  6. Copy the Web app URL (looks like: https://script.google.com/macros/s/ABC.../exec).
  7. Paste that URL into the setup box at the top of this dashboard and click Connect.
  8. The dashboard will auto-create two sheets: Planner (edit content plan here) and Status (auto-updated by buttons).
Tip: Each team member opens this page in their browser and enters their name. When they click Done or Missed, it saves to the shared Google Sheet instantly — visible to everyone.
